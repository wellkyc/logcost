# Security

If you find a way to make logcost leak a secret into its output, crash, hang, use unbounded memory, or write something dangerous to the terminal, please report it privately through [GitHub's vulnerability reporting](https://github.com/wellkyc/logcost/security/advisories/new) instead of opening a public issue.

Please include a small log sample that shows the problem (with real secrets replaced) and the command you ran.

Only the latest release gets fixes.
